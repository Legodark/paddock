# Revisión defensiva de Paddock · 27 de noviembre de 2026

Un agente de seguridad revisó el frontend, las entradas y consultas de la API Flask, la integridad de los artefactos, el empaquetado, las rutas Vercel y GitHub Actions en `main` (`b8c05b2`). El diff de `web/`, `deploy/`, `ci/` y `.github/` frente a la fuente desplegada `9a38be8` está vacío. Los resultados se basan en código, verificaciones locales y consultas de avisos de dependencias. La auditoría de Cloudflare del 16 de noviembre y las pruebas previas de Vercel se usaron como contexto. [Auditoría anterior](security-audit-cloudflare.md) · [Evidencia anterior de producción](entrega-publica-20261117.md).

No se confirmaron vulnerabilidades críticas o altas en el alcance revisado. Surgieron un riesgo de consumo y una mejora de la comprobación previa a incorporar recursos gráficos.

La primera observación es un riesgo de recursos, con impacto en producción aún sin medir. La evidencia previa recoge un límite WAF de 60 solicitudes por minuto por IP y región. El margen mensual compartido de Hobby sigue en #10. Esta revisión utilizó el plan de consulta local, sin medir CPU o memoria en Vercel ni hacer peticiones a la aplicación publicada. [Verificación histórica](limite-rutas-api.md) · [Seguimiento #10](https://github.com/Legodark/paddock/issues/10).

## Controles comprobados

- La API valida campos, tipos, rangos y tamaños, parametriza los valores SQL y abre el catálogo en modo de solo lectura. Comprueba hashes antes de cargar los artefactos compactos. [API](../deploy/vercel/paddock_service/app.py).
- La guarda oficial de rutas pasó para las seis rutas API y los 76 estáticos del paquete preparado. GitHub Actions fija las acciones por SHA y concede permisos de lectura en el flujo revisado. [Guarda](../ci/check_vercel_routing.cjs) · [CI](../.github/workflows/ci.yml).
- `npm audit` devolvió cero avisos en los lockfiles de la web y del constructor. `pip-audit` estricto contra PyPI devolvió cero avisos para siete dependencias fijadas de la API y ocho del paquete local, incluido `vercel-runtime` 0.24.3. El Flutter archivado está fuera de esta comprobación de dependencias.
- El paquete local de referencia tiene 76 archivos públicos, 504.634 bytes en bruto y 289.248 bytes gzip sumando cada archivo. Quedan 10.752 bytes gzip frente al límite de CI. Este dato se usa para dimensionar la propuesta visual. [Presupuesto](../ci/budgets.json) · [Plan de diseño](plan-diseno-regreso-al-futuro.md).
